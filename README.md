# CS360 Multi-Campus WAN Project

This repository contains the Cisco Packet Tracer files and supporting evidence for the CS360 university multi-campus WAN project.

## Phase 1 Status

- Cisco Packet Tracer installed and opened successfully.
- Packet Tracer interface, devices and cable types reviewed.
- A small practice topology containing one PC, one switch and one router was created.
- The IPv4 addressing plan and static-routing approach were selected.

## Next Period

The complete topology will be created and verified. Device addressing, router interfaces, the serial WAN link, static routes and end-to-end connectivity will be done before the Phase 2 submission.
